### 👨‍💻 Sobre Mim

Olá! Sou desenvolvedor de software focado em **Front-End & Full Stack**, apaixonado por arquitetar aplicações que unem **alta performance, design limpo, acessibilidade real (WCAG 2.2 AA)** e arquiteturas robustas de dados em tempo real.

- 🔭 **Atualmente construindo:** Interfaces modernas em **React 19**, **TypeScript** e **Tailwind CSS v4**, integradas a bancos de dados relacionais **PostgreSQL / Supabase**.
- ⚡ **Diferenciais Técnicos:** Otimização de renderização (SSG/SSR, zero FOUC, métricas Core Web Vitals), animações fluidas a 60 FPS com **GSAP**, modularização limpa em ES6+, e raciocínio algorítmico comprovado em **Java** e **C# / Unity**.
- 🎯 **Objetivo:** Contribuir em projetos inovadores como desenvolvedor Front-End / Full Stack em times de engenharia de software de alto nível.
